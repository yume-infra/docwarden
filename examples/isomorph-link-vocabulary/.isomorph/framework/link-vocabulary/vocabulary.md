# link vocabulary

## Terms

- `link-example`: a markdown target whose link surfaces should be checked.
- `short-ofm-link`: OFM wikilink with a target that lacks an explicit path.
- `ofm-path-alias`: OFM wikilink with an explicit target path and display alias.

## Naming Surface

- `link-example`
- `short-ofm-link`
- `ofm-path-alias`
