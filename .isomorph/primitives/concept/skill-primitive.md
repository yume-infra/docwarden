# skill-primitive

## Designation

Canonical: `skill-primitive`

Aliases:

- skill primitive

## Definition

skill-primitive 是 local isomorph primitive，用来把一个 future skill 建模成 agent behavior intervention。

它从 capability 开始：先说明这个 future skill 要给 agent 的行为干预能力，并用 repeated pressure scenario 证明这个能力确实需要存在。

随后它继续表达 trigger、soft boundary、hard boundary、workflow、semantic basis、export shape 和 validation。

v0 可以从 semantic material 产出 `codex-skill` export draft，但不 materialize 最终 `SKILL.md` artifact。
