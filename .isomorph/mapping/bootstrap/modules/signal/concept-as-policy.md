# concept-as-policy

## Definition

`concept-as-policy` 表示 concept module 的命名语言可能滑向 policy 的约束语言。

## Trigger

- `frontmatter.kind == concept`
- `heading in [Definition, Naming Need]`
- `section contains MUST / SHOULD / MUST NOT`
