# promote output content format boundary

1. 本轮对象是 promote 后内容生产，不是 pick 后 user context。
2. 本轮输入是已通过 review 的 promote delta，不是 task raw material。
3. 本轮输出是 `spec / guide / wiki` 的格式实例候选，不是真实写入长期层。
4. `spec / guide / wiki` 是三种不同内容表达，不是同一模板换目录。
5. `spec module` 服务 agent 执行规则。
6. `guide page` 服务 user 理解路径。
7. `wiki node` 服务可链接项目知识。
8. docwarden 提供来源 review、已确认 promote delta、实体落点和写入流程。
9. contexta 后续承接 template、内容字段、module / assertion 和 semantic lint。
10. 本轮不修改 `.contexta/templates/`，不重新设计 review surface，不重新判断 promote / pick 实体落点。
