# review-surface

## Whole

review surface 是为了让用户低成本审核 task material 主线增量而生成的临时审核整体。

## Part

- `lead`：给用户直接看的最小审核面。
- `backing`：支撑 lead 的证据、上下文和展开材料。
- `decision`：用户审核后的结果记录。

## Stable Semantic Boundary

review surface 的稳定边界是“服务一次用户审核”。

它不是 spec、guide 或 wiki，也不直接成为 stable material。

review surface 只能通过用户审核后的 route / promote / pick 进入后续层级。
