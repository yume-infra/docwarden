# definition

## Marker

`def-*`

`def-*` 是 definition locator prefix，只提供稳定地址。

## Surface

`## Definition`

## Applies To

- concept module 的正面定义。
- signal module 的 warning name definition。
- 其他 module 中明确承担 definition surface 的 assertion。

## Boundary

`def-*` 不用于 policy `Rules`、relation `Reading`、example 判断材料或 code fence 中的样例。

`def-*` 不判断 assertion 是否正确，也不替代 Definition surface 对内容角色的约束。
